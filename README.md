# Первое приложение на Django

## Суть проекта:

Разрабатываем бэкэнд дя приложения учебной платформы на django. С использованием Django REST Framework (DRF) 

### Технический стек:
В проекте используются:

* Менеджер пакетов `Poetry`.
* Фреймворк `Django`
* Фреймворк `Django REST Framework`

Для проекта требуется:
- версия python не ниже `3.13`,
- Poetry не ниже `2.0.0`
- Django не ниже версии `6.1.1`
- Django REST Framework не ниже версии `3.18.3`


### Установка:

1. Склонируйте проект на свое локальное окружение командой:  
   git clone https://github.com/Uriy-T/skypro_rdf_study.git

2. Убедитесь, что в среде разработки для проекта используются интерпретатор python и poetry версии в соответствии с указанными требованиями.

3. Для установки всех необходимых зависимостей выполните команду:
   ```bash
   poetry install

### Реализация

На момент сдачи в реализации: 
* создан базовый Django проект;
* создано приложение `courses`, включающее модели `CourseModel` и `LessonModel`;
* создано приложение `users`, включающее модель `MainUser`;
* реализованы контроллеры для CRUD операций всех моделей;
